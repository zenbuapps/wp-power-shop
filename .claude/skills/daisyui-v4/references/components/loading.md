### loading
Loading shows an animation to indicate that something is loading

[loading docs](https://v4.daisyui.com/components/loading/)

#### Class names
- component: `loading`
- style: `loading-spinner`, `loading-dots`, `loading-ring`, `loading-ball`, `loading-bars`, `loading-infinity`
- size: `loading-xs`, `loading-sm`, `loading-md`, `loading-lg`

#### Syntax
```html
<span class="loading loading-spinner loading-md"></span>
```

#### Rules
- A style class name is required — `loading` on its own has no animation
- The element is empty; the animation is drawn by CSS
- Set the color with a text color utility such as `text-primary` or `text-error`
- Put a `loading` inside a `btn` to render a loading button
