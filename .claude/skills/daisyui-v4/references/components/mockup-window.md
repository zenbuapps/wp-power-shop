### mockup-window
Window mockup shows a box that looks like an operating system window

[mockup-window docs](https://v4.daisyui.com/components/mockup-window/)

#### Class names
- component: `mockup-window`

#### Syntax
```html
<div class="mockup-window border-base-300 border">
  <div class="border-base-300 flex justify-center border-t px-4 py-16">Hello!</div>
</div>
```

#### Rules
- `mockup-window` draws the title bar dots automatically — there is no toolbar part to add
- Add `border-base-300 border` for the outlined look, or `bg-base-300 border` for the filled look
- The window content is a normal `<div>` inside the mockup
