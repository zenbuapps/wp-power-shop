### skeleton
Skeleton is a component that can be used to show a loading state of a component

[skeleton docs](https://v4.daisyui.com/components/skeleton/)

#### Class names
- component: `skeleton`

#### Syntax
```html
<div class="skeleton h-32 w-32"></div>
```

#### Rules
- `skeleton` has no size of its own — always add width and height utilities
- Add `rounded-full` for a circular placeholder such as an avatar
- Compose several skeletons with flex or grid utilities to mirror the shape of the real content
