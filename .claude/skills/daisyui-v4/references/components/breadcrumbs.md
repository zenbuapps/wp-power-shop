### breadcrumbs
Breadcrumbs helps users to navigate through the website

[breadcrumbs docs](https://v4.daisyui.com/components/breadcrumbs/)

#### Class names
- component: `breadcrumbs`

#### Syntax
```html
<div class="breadcrumbs text-sm">
  <ul>
    <li><a>Home</a></li>
    <li><a>Documents</a></li>
    <li>Add Document</li>
  </ul>
</div>
```

#### Rules
- `breadcrumbs` goes on a wrapper element and the items live in a nested `<ul>` — the class is NOT on the `<ul>` itself
- The separators are generated by CSS, do not add them manually
- The last item is usually plain text, not a link
- An item can contain an icon before the text
- Add `max-w-xs` (or any max width) to the wrapper to make a long breadcrumb scroll horizontally
