# 分潤夥伴自助報表

> 路由：`/profit-report/{slug}/`
> 前端路由：`#/login`、`#/dashboard`、`#/change-password`

## 頁面說明

分潤夥伴查看自己銷售與分潤狀況的公開頁面，與後台**完全隔離**：

| 維度 | 分潤夥伴報表 | 後台 |
|------|--------------|------|
| 掛載點 | 獨立的前端程式 | 後台單頁應用 |
| 佈景主題 | **完全脫離**（自行輸出 HTML 骨架，不走頁首頁尾） | 走後台外框 |
| 認證 | HttpOnly Cookie + 工作階段中的夥伴識別 | WordPress nonce |
| 資料層 | 直接呼叫 HTTP，不使用後台的資料層 | 六個資料層 |
| 回應形狀 | 裸 payload | `{code, message, data}` |

脫離佈景主題是刻意的：避免後台工具列、佈景主題樣式與其他外掛的注入污染。

## 區塊配置

### 1. 登入頁 `#/login`

| 元素 | 說明 |
|------|------|
| 夥伴識別欄位 | 從網址帶入且**停用**（防打錯字） |
| 密碼欄位 | 瀏覽器自動填入提示為「目前密碼」 |
| 登入按鈕 | 送出中停用；被鎖定期間顯示剩餘秒數並停用 |
| 一次性提示 | 讀取網址參數顯示「密碼已變更」等提示（白名單比對） |

- 失敗訊息一律為統一的錯誤，不區分「識別不存在」與「密碼錯誤」
- 被鎖定時解析回應標頭的等待秒數並倒數；無法解析為數字時**不得**讓按鈕永久停用

### 2. 儀表板 `#/dashboard`

| 區塊 | 說明 |
|------|------|
| 日期區間篩選 | 5 個預設區間（本月 / 上月 / 近 7 天 / 近 30 天 / 自訂） |
| KPI 四卡 | 總銷售 / 待結算 / 已結算 / 已退款；手機版直向堆疊 |
| 趨勢圖 | 折線圖，依日期區間分組 |
| 結算明細表 | 桌機表格 / 手機卡片式；支援結算狀態篩選 |
| 修改密碼入口 | 導向 `#/change-password` |
| 登出 | 一律清除本機狀態，即使 API 失敗 |

- 任一查詢回 401 時自動導回登入頁（含防迴圈判斷）
- 載入中顯示載入畫面；元件錯誤由錯誤邊界接住，不讓整頁白畫面

### 3. 修改密碼 `#/change-password`（高風險）

| 欄位 | 說明 |
|------|------|
| 目前密碼 | 必填 |
| 新密碼 | 必填，需 ≥ 8 字元且含英文與數字 |
| 確認新密碼 | 必填，需與新密碼一致 |

**表單規則**：新密碼不得與目前密碼相同；確認密碼不一致時不允許送出。

**送出按鈕三重守門**：送出中 / 冷卻中 / 已成功，任一成立即停用。

**成功後**：清除表單 → 導向登入頁並附帶提示參數（後端已撤銷所有既有 token）。

## 高風險紀律（修改密碼頁）

| # | 紀律 |
|---|------|
| 1 | 明文密碼**只**存在表單狀態，不進任何快取 / 儲存 / 記錄 |
| 2 | 不在主控台輸出密碼 |
| 3 | 失敗後清空欄位採分支策略：弱密碼只清目前密碼；其他全清 |
| 4 | 送出按鈕三重守門 |
| 5 | 成功後強制導向登入頁 |
| 6 | 清除請求層保存的變數（防開發者工具窺看） |
| 7 | 表單規則阻擋「新舊相同」與「兩次不一致」 |
| 8 | 離開頁面時清除待執行的計時器（防中途離開後仍觸發導向） |

## 安全紀律

| 項目 | 規則 |
|------|------|
| token 儲存 | **永不**進任何前端可讀的儲存；由 HttpOnly Cookie 承載 |
| 工作階段保存內容 | 只有夥伴識別資訊（id / name / slug / 到期時間），**不含憑證** |
| 跨夥伴防護 | 網址的 slug 與本機識別不一致時：狀態視為載入中（非已登入）**且**夥伴資料遮蔽為空，兩道防線缺一不可 |
| 報表範圍 | 永不從網址參數帶夥伴識別；後端由 token 鎖死 |
| 登出 | 一律執行本機清除，不依賴 API 成功 |

## 隔離驗收

打包後的夥伴報表程式必須**不含**任何後台模組。
驗收方式是對產出的程式碼比對後台專屬的識別字（後台進入點、後台資料層名稱、
後台 nonce 標頭等），全部應為 0 命中。

## 失敗降級

| 情境 | 行為 |
|------|------|
| 夥伴識別不存在 | 404 |
| 前端資源清單缺少對應項目 | 503 維護中 + 禁止快取（不得顯示空白頁） |
| 報表查詢失敗 | 顯示錯誤訊息，不讓整頁白畫面 |
