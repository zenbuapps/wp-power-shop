# 分潤賣場前台

> 路由：`/profit-shop/{slug}/`（獨立頁面模式）
> 或以短碼 `[power_shop_profit_shop id="{post_id}"]` 嵌入任意頁面

## 頁面說明

顧客瀏覽賣場商品並加入購物車的公開頁面。**畫面全部由 PHP 印出**，
互動層是一支手寫 vanilla JS（不經前端打包流程）。

兩條渲染路徑（獨立頁面 / 短碼）輸出**逐字相同的 DOM**，
外層容器一律為 `<div>`。

- 獨立頁面走佈景主題的頁首與頁尾（與夥伴報表頁完全脫離佈景主題不同）
- 短碼不注入標題與正規網址（宿主頁面自己有）
- 樣式全部由 powerhouse 統一提供，本外掛**沒有任何自有 CSS**

## 區塊配置

### 1. 賣場標題與站長自訂內容

- 賣場名稱
- 賣場內容（區塊編輯器 / HTML / 短碼皆可；⚠ 頁面建構器排版的內容不會被渲染）

### 2. 排程區塊（僅非販售期間顯示）

依三個**互相獨立**的旗標決定印不印，全部關閉時整段不印：

| 旗標 | 內容 |
|------|------|
| 倒數計時 | 四格倒數盤（天 / 時 / 分 / 秒）；天數 > 99 時改以純文字呈現 |
| 自訂文字 | 站長輸入的一段文字（上限 200 字元）；文字為空時不印 |
| 顯示商品 | 照印商品卡片但按鈕停用（**預設值**，等同本功能上線前的既有行為） |

- 首屏數字由 PHP 以**伺服器時間**印出；之後每秒遞減交給 JS
- 歸零後重新載入頁面（初始剩餘為 0 時不排程，避免無限迴圈）

### 3. 商品卡片格線

| 元素 | 說明 |
|------|------|
| 商品圖片 | 懶載入；hover 放大 |
| 商品名稱 | 直接印在 HTML 內（SEO） |
| 價格 | 賣場覆寫後的劃線原價與特價；可變商品顯示價格區間 |
| 已售件數 | 真實銷量 + 灌水購買人數；合計為 0 或設定關閉時不顯示 |
| 動作元素 | **每張卡片只印一個**（見下表） |

| 商品類型 | 動作元素 | 無 JS 時的行為 |
|----------|----------|----------------|
| simple | 直接送出的加購表單 | 直接加入購物車 |
| 其他（含可變商品） | 連往商品單頁且帶賣場識別的連結 | 到單頁選規格再加購 |

JS 載入後會攔截卡片點擊改開商品對話框，並把按鈕文字換成對話框版本的文案。
因此**不需要**任何 `<noscript>` 樣式或第二顆按鈕。

**沒有任何可購買規格的商品**：卡片標記為停用並顯示「暫無可購買規格」，
且該商品**不印出對話框**。

### 4. 商品對話框（每個可購買商品各一個）

以原生 `<dialog>` 實作，開啟時自動進入瀏覽器的頂層，天然蓋過所有元素。

| 區塊 | 說明 |
|------|------|
| 圖片區 | 主圖 + 縮圖切換；選中變體有專屬圖片時自動切換主圖 |
| 商品資訊 | 名稱、價格、庫存文案、已購買人數 |
| 商品描述 | 過長時提供「展開 / 收合全部內容」 |
| 變體屬性選擇 | 可變商品才有；每組屬性一列按鈕 |
| 數量選擇器 | `−` / 輸入框 / `+`，夾在 1 與可購買上限之間 |
| 加購按鈕 | 含載入指示與文字兩個區塊 |
| 就地錯誤列 | 加購失敗時顯示於按鈕下方，含「查看購物車」連結 |

**顯示開關**：`showStock` 控制庫存文案、`showBuyerCount` 控制已購買人數。
⚠ 這兩個開關目前**沒有任何後台 UI**（見 tech-debt TD-22）。

### 5. 成功通知

- 印在賣場容器內（非對話框內），固定於畫面上方置中
- 只在賣場處於販售期間時才印出容器
- 成功時**先關閉對話框再顯示通知**——原生對話框開啟時位於瀏覽器頂層，
  底層元素不論層級多高都在它之下

### 6. WooCommerce 訊息區塊

賣場頁不是 WooCommerce 的樣板頁，因此必須**自行輸出**訊息區塊，
否則原生表單加購後畫面除了重新載入之外沒有任何變化。

⚠ 目前原生表單加購成功後訊息內容是空的（見 tech-debt TD-49）。

## 互動行為（vanilla JS）

| 行為 | 說明 |
|------|------|
| 開啟對話框 | 攔截卡片點擊；查找限定在最近的賣場容器內（支援一頁多賣場） |
| 縮圖切換 | 點擊或鍵盤操作切換主圖 |
| 描述展開收合 | 高度量測必須在對話框開啟後才準確 |
| 數量加減 | 夾住上下限 |
| 變體選擇 | 比對變體 → 重寫變體與屬性隱藏欄位、更新價格 / 庫存 / 上限 / 按鈕狀態 |
| 非同步加購 | 攔截表單，改以 WooCommerce 原生的非同步加購端點送出 |
| 倒數計時 | 每秒遞減；歸零後重新載入 |

## DOM 契約

`data-ps-*` 屬性群是跨語言（PHP ↔ JS）的介面。改動任一項會讓互動**靜默失效**
且沒有任何錯誤訊息。完整清單見前台 JS 檔頭註解。

主要項目：

```
.ps-profit-shop-front[data-ps-shop]     賣場容器（多賣場的查找邊界）
[data-ps-product-id]                    商品卡片
[data-ps-modal-for]                     對應商品的 <dialog>
[data-ps-form]                          加購表單（非同步攔截點）
[data-ps-submit-spinner|label|error]    加購按鈕與就地錯誤列
[data-ps-toast|toast-body|toast-label]  成功通知
[data-ps-countdown][data-ps-countdown-target]  倒數容器與目標毫秒數
[data-ps-cd-unit] / [data-ps-cd-plain]  倒數的數字格與 > 99 的純文字退路
```

## 降級路徑

| 關卡 | 不成立時 |
|------|----------|
| JavaScript 啟用 | 卡片印出的原生表單 / 連結即完整加購路徑 |
| 支援原生對話框 | 同上，不攔截卡片點擊 |
| 具備非同步請求能力 | 不註冊表單攔截，走原生表單送出 |
| 能組出加購內容 | 不攔截送出，交給瀏覽器執行原生表單 |

第四關涵蓋：商品類型不在支援清單、未選滿變體、**選中的變體含任意屬性**、
缺少賣場識別。

⚠ 「含任意屬性的變體加購會換頁、沒有成功通知」是**正確**的降級，不是缺陷。
